# Icon Catalog

Icons are white PNGs so they can be tinted. Use the key (the category and name, without the extension) with `DFW.Icons.Draw(key, x, y, w, h, color)`, `DFW.Draw.Icon(key, x, y, size, color)`, the `SetIcon(key)` method on buttons, frames and navigation rows, or the `icon` field of a module definition.

Example: `button:SetIcon("actions/check")`
